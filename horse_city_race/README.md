# City Gallop: Horse Race

말을 타고 도시를 질주하며 다른 세 마리 말과 경주하는 간단한 파이썬(pygame) 게임입니다.
장애물(드럼통, 라바콘, 물웅덩이)을 점프로 피하고, 코인을 모으며 결승선(2200m)까지 먼저 도착해 보세요.

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python main.py
```

## 조작 방법

- `SPACE` / `ENTER` : 게임 시작
- `SPACE` / `↑` : 점프 (장애물 피하기)
- `R` : 게임오버 또는 결승 후 다시 시작
- `ESC` : 종료

## 게임 규칙

- 화면 상단 미니 순위표에서 나(갈색 말)와 적토마, 백마, 흑마의 진행 거리를 실시간으로 비교할 수 있습니다.
- 장애물에 부딪히면 그 즉시 경주가 종료됩니다.
- 결승선(2200m)에 먼저 도착할수록 높은 순위를 얻습니다.
- 시간이 지날수록 속도가 빨라져 난이도가 점점 올라갑니다.
- 코인을 모으면 점수가 올라갑니다 (기록용).

## 사운드

외부 음원 파일 없이 `audio.py`에서 코드로 직접 합성한 효과음을 사용합니다 (점프, 코인 획득, 말발굽 소리, 충돌, 결승 팡파레, 메뉴 선택음). 시스템에 오디오 장치가 없으면 자동으로 무음 모드로 동작하며 게임 진행에는 영향이 없습니다.
