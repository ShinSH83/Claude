# 사주풀이 (Saju Fortune)

생년월일(과 태어난 시간)을 입력하면 사주팔자(四柱八字)를 뽑아 간단한 풀이를 보여주는
정적 웹사이트입니다. 서버나 빌드 도구 없이 HTML/CSS/JS만으로 동작합니다.

## 실행

별도 설치 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.
로컬 서버로 실행하려면:

```bash
python3 -m http.server 8000
```

이후 `http://localhost:8000` 접속.

## 기능

- 생년월일과 태어난 시간(모를 경우 체크박스로 생략 가능)으로 년주·월주·일주·시주 계산
- 오행(목/화/토/금/수) 분포를 막대그래프로 표시
- 일간(日干)에 따른 간단한 성격 해설
- 오행 강약에 따른 전체적인 기운 해설

## 계산 방식

- **일주**: 60갑자는 날짜와 무관하게 60일 주기로 순환하므로, 검증된 기준일
  (2019-01-27 = 갑자일, Julian Day 2458511)로부터의 날짜 차이를 60으로 나눈
  나머지로 계산합니다.
- **연주**: 1984년(갑자년)을 기준으로 60년 주기로 계산합니다.
- **월주/연도 경계**: 태양의 겉보기 황경(黃經)을 저정밀 공식(오차 약 0.01도
  이내)으로 계산하여, 절기(입춘·경칩 등 30도 간격)가 바뀌는 시점을 기준으로
  월지와 연도 경계(입춘)를 판정합니다. 한국표준시(UTC+9) 기준으로 변환하여
  계산합니다.
- **시주**: 태어난 시간과 일간을 바탕으로 오자시둔법(五子時遁法)에 따라 계산합니다.

## 참고 사항

이 사이트는 전통 명리학의 기본 원리를 바탕으로 한 간이 계산·해설이며, 십신·대운·
신살 등을 포함한 전문적인 사주 감정을 대신하지 않습니다. 자시(23:00~00:59)
전후의 날짜 처리(조자시/야자시)는 통용되는 방식 중 하나를 단순화하여 적용했습니다.
