# City Gallop: Horse Race

말을 3인칭 시점(TPS)에서 직접 조종하며 트랙을 달리는 파이썬(pygame) 미니 카트 레이싱 게임입니다.
자유롭게 움직이는 다른 세 마리 말과 트랙 위에서 부딪히고 견제하며, 아이템으로 부스트를 받아 3랩을 먼저 완주해 보세요.

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python main.py
```

## 조작 방법

- `↑` : 가속
- `↓` : 감속/브레이크
- `←` / `→` : 좌우 조종
- `SPACE` : 점프
- `SPACE` / `ENTER` : 시작 화면에서 게임 시작
- `R` : 완주 후 다시 시작
- `ESC` : 종료

## 게임 규칙

- 트랙은 3랩을 도는 루프이며, 완주 시 최종 순위가 표시됩니다.
- 우측 상단에 현재 등수(예: `2위 / 4`)와 랩 수만 표시됩니다.
- 트랙을 벗어나 잔디밭으로 나가면 속도가 크게 줄어듭니다.
- 번개 모양 아이템을 지나가면 일정 시간 동안 부스트(속도 증가)를 받습니다.
- 다른 말들도 플레이어처럼 좌우로 자유롭게 움직이며, 서로(그리고 플레이어와도) 가까이 붙으면 부딪혀 밀려나고 속도가 살짝 줄어듭니다.

## 사운드

외부 음원 파일 없이 `audio.py`에서 코드로 직접 합성한 효과음을 사용합니다 (점프, 아이템 획득, 부스트, 충돌(밀림), 말발굽 소리, 완주 팡파레, 메뉴 선택음). 시스템에 오디오 장치가 없으면 자동으로 무음 모드로 동작하며 게임 진행에는 영향이 없습니다.
