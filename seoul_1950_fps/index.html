서울 수복 작전 1950

1950년, 국군 병사가 되어 북한군에게 점령된 서울 시가지에서 전투를 벌인다.
건물 잔해와 바리케이드 사이를 뚫고 서울을 수복하라.

조작법

  • W / A / S / D — 전진 / 좌 이동 / 후진 / 우 이동
  • 마우스 — 시점 회전 (클릭하여 마우스 잠금)
  • ← / → — 시점 회전 (키보드 대체 조작)
  • Shift — 달리기
  • 마우스 좌클릭 — 사격 (M1 개런드)
  • R — 재장전
  • ESC — 일시정지 / 마우스 잠금 해제
