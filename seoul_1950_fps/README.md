# 서울 수복 작전 1950 (Operation Recapture Seoul 1950)

픽셀아트 기반 3D FPS 게임 — 1950년 6.25전쟁 당시 서울 시가전을 배경으로 한다.
울펜슈타인3D와 같은 방식의 레이캐스팅(raycasting) 엔진으로 3D처럼 보이는 픽셀아트 화면을 순수 HTML5 Canvas + JavaScript로 구현했다. 별도 빌드 도구나 외부 이미지 자산 없이 모든 텍스처는 코드로 생성한다.

## 실행 방법

정적 파일이므로 별도 서버 없이 `index.html`을 브라우저로 열어도 되지만, 일부 브라우저의 파일 접근 제한을 피하려면 로컬 서버 사용을 권장한다.

```bash
cd seoul_1950_fps
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## 시나리오

플레이어는 국군(대한민국 육군) 병사로, 북한군에게 점령된 서울 시가지에 투입되어
건물 잔해와 바리케이드가 늘어선 거리를 뚫고 서울을 수복하는 작전을 수행한다.

## 1950년 고증 요소 (현재 골격 단계 반영분)

- **무기**: M1 개런드(M1 Garand) — 1950년 국군/미군의 표준 제식 소총, 8발 클립(en-bloc clip) 급탄 방식을 탄약 표시(8/8)에 반영.
- **복장/장비**: 올리브 드랍(olive drab) 계열 국군 야전 색상을 화면 하단 무기 스프라이트에 사용.
- **배경**: 종로 일대를 연상시키는 붉은 벽돌 상가 건물, 관공서 콘크리트 건물, 포격으로 파괴된 건물 잔해, 국군이 설치한 모래주머니 바리케이드로 시가전 지형을 구성.
- **위협**: 지뢰(6.25전쟁 당시 시가지에 실제로 매설되었던 위협 요소)를 밟으면 체력이 감소하는 환경 위험 요소로 구현.

실제 인물/부대/제품을 사칭하지 않는 선에서, 색상·형태·명칭을 통해 시대적 분위기를 재현했다.
향후 단계에서 스프라이트 기반 병사 모델, 정밀한 지형(숭례문·한강 등 랜드마크), 사운드를 추가해 고증 수준을 높일 예정이다.

## 조작법 (현재 구현된 기본 골격)

| 입력 | 동작 |
|---|---|
| `W` / `S` | 전진 / 후진 |
| `A` / `D` | 좌 / 우 이동(스트레이프) |
| 마우스 이동 (클릭 후 포인터 잠금) | 시점 좌우 회전 |
| `←` / `→` | 시점 좌우 회전 (마우스 대체 조작) |
| `Shift` | 달리기 |
| 마우스 좌클릭 | 사격 (탄약 소모, 클립 소진 시 재장전 필요) |
| `R` | 재장전 (M1 개런드 8발 클립, 약 0.9초 소요) |
| `Esc` | 포인터 잠금 해제 → 일시정지 |

## 체력 시스템

울펜슈타인3D처럼 화면 좌측 하단에 100%(100/100) 체력 게이지를 표시한다.
- 체력 50% 초과: 녹색
- 25%~50%: 노란색
- 25% 미만: 빨간색

현재 골격 단계에서는 지도에 배치된 지뢰(⚠ 지뢰 주의 경고 표시)를 밟으면 25의 피해를 입도록 구현되어 있으며, 체력이 0이 되면 "전사(戰死)" 게임오버 화면이 표시되고 재시작할 수 있다. 이후 단계에서 북한군 적 유닛과의 교전으로 인한 피해가 추가될 예정이다.

## 파일 구조

```
seoul_1950_fps/
├── index.html          # 시작/일시정지/게임오버 화면 및 캔버스
├── style.css            # UI 스타일 (픽셀아트 렌더링 설정 포함)
└── js/
    ├── map.js            # 시가전 지도 데이터 (건물/바리케이드/지뢰 타일)
    ├── textures.js        # 벽/바닥 픽셀아트 텍스처 절차적 생성
    ├── player.js          # 플레이어 이동, 충돌, 체력 로직
    ├── input.js           # 키보드 및 마우스(포인터락) 입력
    ├── raycaster.js       # DDA 레이캐스팅 3D 렌더링 엔진
    ├── hud.js             # 체력바, 무기, 조준점, 탄약 등 HUD
    └── main.js            # 게임 루프 및 상태(시작/플레이/일시정지/게임오버) 관리
```
